# 首版需求与比赛规则

2026-11-02：独立仓库 Prostream/PhantomBZ_BvB，基于 PhantomGladiator v0.37.6。初期私有开发，同日按用户要求公开开源。

## 已确认

阵营战、原生数值、无仇恨自由镜头、介绍待机、保存阵容和站位、一键重置。Boss 不动即可，不要求暂停世界或中途冻结投射物。首版两队总血量。地图不限，用用户已有一周目存档。

## 当前规则（用户已确认）

同队友好、异队敌对、允许围攻。召唤物继承队伍但不独立决定胜负。优先原生转阶段，未识别阶段替换标记待验收，不伪造。原生等级、按游戏数值，游戏和召唤都必须为逆天者，工具不强改存档；不是一周目或难度不符时拒绝召唤。关闭不倒下与数值统一。

## 流程

读档进入地图 → 无仇恨 → 召唤两队（默认定身）→ 保存阵容和站位 → 自由镜头介绍 → 开战 → 真实结果。

重置先核对保存阵容，再清理本局对象并确认恢复，逐只重新生成，任何一步失败立即停止，不自动重试或开战。没有保存阵容不得先清场。同地图复用原站位；换地图须显式“在当前位置布置”，按玩家位置与朝向变换相对站位，不把旧世界坐标用到新地图。

队伍总血量仅参赛本体，不含小怪。死亡者仍计入初始总上限，避免减员导致血条回满。未知读数不判死。总血量不是归一化战力。

## 验收

阵营与召唤物归队；特殊范围技/反弹需实测。介绍定身但镜头可动，开战恢复。近远景真实掉血与完整投技。重置不重复、不补血、不残留。跨地图坐标隔离、相对布阵与转向。清理/读取失败拒绝继续。多阶段及未知状态不误判胜负。
